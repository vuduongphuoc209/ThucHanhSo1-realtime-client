Các chức năng chính:

| Chức năng         | Công nghệ                  |
| ----------------- | -------------------------- |
| SPA               | React + React Router       |
| UI                | Ant Design / Tailwind CSS  |
| RESTful API       | Axios + Express.js         |
| Đăng nhập/đăng ký | JWT                        |
| Chat realtime     | WebSocket / Socket.IO      |
| Quản lý state     | Redux Toolkit              |
| Offline           | Service Worker + IndexedDB |
| PWA               | Vite PWA Plugin            |
| Database          | MongoDB                    |
| Ngôn ngữ          | TypeScript                 |

2. Kiến trúc tổng thể
   Bạn có thể xây dựng theo mô hình:

```mermaid
                       ┌─────────────────────┐
                    │      React SPA      │
                    │   React + TypeScript│
                    └──────────┬──────────┘
                               │
                 ┌─────────────┴─────────────┐
                 │                           │
                 ▼                           ▼
          RESTful API                 WebSocket
          Axios / HTTP               Socket.IO
                 │                           │
                 └─────────────┬─────────────┘
                               ▼
                    ┌─────────────────────┐
                    │    Node.js Server   │
                    │ Express + Socket.IO │
                    └──────────┬──────────┘
                               │
                               ▼
                       ┌──────────────┐
                       │   MongoDB    │
                       └──────────────┘

                    ┌─────────────────────┐
                    │        PWA          │
```
