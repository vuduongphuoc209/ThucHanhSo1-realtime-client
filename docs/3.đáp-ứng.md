Các yêu cầu bài tập được đáp ứng
trình bày với giảng viên như sau:

| Yêu cầu          | Phần triển khai                               |
| ---------------- | --------------------------------------------- |
| SPA              | React + React Router                          |
| WebSocket        | Socket.IO                                     |
| Ứng dụng chat    | Conversation + Message                        |
| RESTful API      | Express REST API                              |
| Angular          | ⚠️ Đề bài ghi Angular nhưng bạn sử dụng React |
| PWA              | Vite PWA                                      |
| Offline          | Service Worker + Cache + IndexedDB            |
| Database         | MongoDB                                       |
| Authentication   | JWT                                           |
| State Management | Redux Toolkit                                 |
| Language         | TypeScript                                    |
