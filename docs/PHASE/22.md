28.1. Cài PWA
Trong thư mục frontend:
cd client
Cài:
npm install -D vite-plugin-pwa
Đây là package được tài liệu chính thức của Vite PWA khuyến nghị cho việc tích hợp PWA vào Vite.
Tiếp theo cài IndexedDB wrapper:
npm install idb

28.2. Cấu hình vite.config.ts
vite-plugin-pwa có thể tự sinh manifest, service worker và đăng ký service worker; devOptions.enabled cho phép kiểm tra service worker ngay trong development.
