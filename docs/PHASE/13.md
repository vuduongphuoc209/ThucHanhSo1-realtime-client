Bước tiếp theo: PHASE 18 — Chat Database

Chúng ta sẽ tạo 2 model quan trọng:

Conversation
├── participants
├── type
├── lastMessage
├── createdAt
└── updatedAt

Message
├── conversationId
├── senderId
├── content
├── type
├── isRead
└── createdAt

Sau đó xây:
GET /api/users
GET /api/conversations
POST /api/conversations
GET /api/messages/:conversationId
POST /api/messages

Rồi ngay sau REST API, chúng ta gắn Socket.IO vào server hiện tại để biến Chat UI thành chat realtime thật giữa 2 tài khoản.
